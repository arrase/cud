# Cud Project Guidelines

## Python Coding Standards
- **Strict Import Rules:** NEVER use inline or function-level imports (e.g., placing `import` or `from x import y` inside a function body). All imports MUST be placed at the top of the file, following standard PEP 8 conventions.
- **Elegance and Quality:** The code must be elegant and comply with the highest Python standards.
- **No Shortcuts:** Do not take architectural or structural shortcuts to avoid dependency issues or circular imports. Solve the underlying structural problem properly through refactoring.
